# Tortopedia Article Production Skill

Краткая памятка по использованию skill для производства статей Tortopedia.

## Основной файл

Использовать:

`skills/tortopedia-article-production/SKILL.md`

Подробный source of truth:

`docs/ARTICLE_PRODUCTION_REGULATION.md`

Если правила расходятся, приоритет у более нового и более конкретного регламента.

## Как вызвать skill в новом чате

Минимальный вариант:

> Подключи `skills/tortopedia-article-production/SKILL.md` и продолжаем работу по Tortopedia.

## Новая статья

> Создаём новую статью Tortopedia про [ТЕМА]. Работай по `skills/tortopedia-article-production/SKILL.md`. Начинай с этапа 1 и не переходи к следующему обязательному этапу, пока текущий не завершён.

## Продолжение незавершённой статьи

> Продолжаем статью `[НАЗВАНИЕ]`. Подключи `skills/tortopedia-article-production/SKILL.md`, проверь актуальное состояние репозитория и определи, на каком этапе регламента мы сейчас находимся. Продолжай один шаг за раз.

## Продолжение после паузы или в новом чате

> Работаем над Tortopedia. Подключи `skills/tortopedia-article-production/SKILL.md`, затем проверь `docs/CURRENT_SESSION_STATE.md` и `docs/HANDOFF.md`, если они актуальны. Фактическое состояние репозитория имеет приоритет над документацией. Продолжай с ближайшего незавершённого обязательного этапа.

## Что skill должен обеспечивать

- работу по регламенту сверху вниз;
- RU/UA синхронизацию;
- `ARTICLE_PASSPORT`;
- фактчек практических утверждений;
- итерационную работу с изображениями;
- правило: корректный текст не переписывается под ошибочное изображение;
- интеграцию только утверждённых визуалов;
- проверку aspect ratio и responsive WebP;
- работу через source → build → `_site-pilot` → `publish.ps1`;
- PowerShell 7 + UTF-8;
- осторожную работу с украинским апострофом;
- запрет `git add .`;
- проверку staged diff;
- commit/push только после явного разрешения;
- production-проверку перед статусом `DONE`;
- значение `++` как подтверждение только текущего предложенного шага.

## Рекомендуемый формат работы

`один этап → действие / проверка → результат пользователя → следующий этап`

Не выдавать длинную цепочку будущих команд без отдельного запроса.

## Быстрый старт

Для большинства случаев достаточно этой фразы:

> Подключи `skills/tortopedia-article-production/SKILL.md`, работай строго по нему и по актуальному `docs/ARTICLE_PRODUCTION_REGULATION.md`. Один шаг за раз. Фактическое состояние репозитория важнее памяти и старой документации.
