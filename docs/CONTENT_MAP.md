# Tortopedia — CONTENT MAP

> Живой рабочий документ. Фиксирует принятую структуру контента и развивается по мере появления новых данных GSC, семантики и новых разделов.

---

## 1. Пилотный кластер: «Мастика»

Исторически мастика — одна из самых сильных тем Tortopedia по данным GSC.

Раздел используется как первый полноценный контентный кластер, на котором отрабатываются:

- структура связанных материалов;
- разделение поисковых интентов;
- внутренняя перелинковка;
- обновление старых статей;
- создание недостающих практических материалов;
- двуязычная RU/UA публикация.

Данные GSC и семантика используются как рабочая основа, но распределение запросов между страницами не считается навсегда фиксированным.

При появлении новых данных роли страниц могут уточняться.

## 3. Принцип архитектуры контента

Для раздела «Мастика» используется логика:

```text
базовый ответ
→ конкретная техника
→ частная практическая задача
→ troubleshooting
```

Новая статья должна иметь понятную роль.

Перед созданием страницы нужно определить:

1. какой конкретный пользовательский вопрос она закрывает;
2. существует ли уже страница с тем же интентом;
3. чем новая страница отличается от соседних;
4. откуда на неё должны вести внутренние ссылки;
5. куда пользователь должен перейти после неё.

Нельзя расширять кластер простым созданием множества похожих статей.
