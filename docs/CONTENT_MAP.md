# Tortopedia — CONTENT MAP

> Живой рабочий документ. Фиксирует принятую структуру контента и развивается по мере появления новых данных GSC, семантики, Keyword Planner и новых разделов.

---

## 1. Общий принцип

Tortopedia развивается не по жёсткому старому backlog, а по фактическому спросу и состоянию сайта.

Перед созданием новой статьи нужно проверить:

1. есть ли отдельный пользовательский интент;
2. существует ли уже страница с тем же или близким интентом;
3. есть ли риск каннибализации;
4. подтверждается ли спрос старым семантическим ядром, Keyword Planner, GSC или SERP;
5. какую роль новая статья будет играть в структуре кластера;
6. какие внутренние ссылки должны вести на неё и с неё.

После завершения крупного материала или мини-кластера backlog пересматривается заново.

## 2. Кластер «Мастика»

Исторически мастика — одна из сильных тем Tortopedia.

Кластер уже включает базовые рецепты, техники, хранение, лепку, сушку и отдельные мастер-классы.

### 2.1. Базовая страница

**Как сделать сахарную мастику в домашних условиях: 8 рецептов**

Закрывает широкий интент: рецепт мастики, как сделать мастику, мастика для торта, сахарная мастика, мастика своими руками.

Не создавать рядом вторую общую статью с тем же интентом.

### 2.2. Рецепты по типам

Существующие направления:

- мастика из маршмеллоу;
- шоколадная мастика;
- желатиновая мастика;
- мастика из сгущёнки.

Новые рецептурные страницы создавать только при подтверждённом самостоятельном спросе.

### 2.3. Работа с мастикой

Существующие направления:

- **Как работать с мастикой для торта: инструкция для начинающих**;
- как обтянуть торт мастикой;
- как обтянуть без складок;
- как раскатывать мастику;
- мраморная мастика;
- другие узкие практические техники.

Системная статья для начинающих выполняет роль входной инструкции и связывает рецепты с более узкими действиями.

### 2.4. Окрашивание

Основная страница:

**Как покрасить мастику красителем**

Не дробить тему на отдельные страницы под каждый цвет без подтверждённого спроса.

### 2.5. Хранение мастики

Опубликована отдельная статья:

**Как хранить мастику для торта**

Интент: хранение самой мастики как материала.

Не смешивать с хранением готовых фигурок или уже собранного торта.

### 2.6. Лепка фигурок

Опубликована системная статья:

**Мастика для лепки фигурок**

Она связывает выбор подходящей мастики, подготовку массы, укрепление, лепку, сушку, хранение и отдельные мастер-классы по фигуркам.

Старые мастер-классы по конкретным фигуркам остаются самостоятельными дочерними материалами.

### 2.7. Сушка фигурок

Опубликована отдельная статья:

**Как сушить фигурки из мастики**

Интент отделён от хранения готового декора.

Материал закрывает вопросы сроков, места и температуры сушки, ускорения процесса, использования вентилятора и признаков готовности.

### 2.8. Хранение фигурок

Опубликована отдельная статья:

**Как хранить фигурки из мастики**

Она продолжает практическую цепочку:

лепка → сушка → хранение готовых фигурок

### 2.9. Хранение готового торта с мастикой

Опубликована отдельная статья:

**Как хранить торт с мастикой**

Это отдельный интент, не совпадающий с хранением мастики как материала и хранением декора.

Материал охватывает холодильник, температуру, упаковку, конденсат, сроки, влияние крема и начинки, извлечение из холодильника, заморозку, хранение перед подачей и транспортировкой.

### 2.10. Ошибки и спасение результата

Потенциальное направление, но не текущий приоритет.

Возможные интенты: мастика липнет, рвётся, трескается, слишком мягкая, слишком твёрдая, быстро сохнет, потеет, пузырится, плохо раскатывается, как спасти испорченную мастику.

Отдельные статьи создавать только при подтверждённом самостоятельном спросе.
