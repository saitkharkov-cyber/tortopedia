### Главная страница: блок новых статей

Статус: реализовано.

На RU и UA главных работает автоматический блок:

```text
Новые статьи
Нові статті
```

Он выводит 6 последних материалов из коллекций `recentRu` / `recentUk`.

Старый статический блок популярных рецептов удалён, чтобы не перегружать главную двумя похожими сетками карточек.

Live проверен пользователем — всё корректно.

Следующий самостоятельный кластер: `украшение торта для мужчины`.

### 1. Общая статья-хаб

Планируемый глобальный `post_id`: 1043.

Рабочий интент: `как украсить торт для мужчины в домашних условиях`.

Существующий материал `/kak-ukrasit-tort-na-den-rozhdeniya-muzhu/` не является общей статьёй: это отдельный пошаговый мастер-класс по оформлению торта-смокинга мастикой.

Новый материал должен закрывать более широкий интент:

- идеи оформления мужского торта;
- своими руками;
- без мастики;
- крем;
- шоколад;
- сладости;
- топперы;
- надписи;
- тематическое оформление;
- варианты на день рождения и юбилей.

Существующий мастер-класс со смокингом использовать как отдельный дочерний материал и дать на него внутреннюю ссылку из общего хаба.

Keyword Planner подтвердил актуальный спрос:

- `торт на день рождение мужчине` — 100–1 тыс.;
- `как украсить торт для мужчины в домашних условиях` — 10–100;
- `оформление торта для мужчины` — 10–100;
- `торт для мужчины без мастики` — 10–100;
- `торт для мужчины своими руками` — 10–100;
- `торт для мужа на день рождения` — 10–100;
- `торт мужчине на юбилей` — 10–100.

GSC показывает, что существующий мастер-класс уже ранжируется по широким запросам, поэтому новую общую статью нужно чётко развести с ним по интенту и связать внутренней перелинковкой.


При публикации новых материалов достаточно корректно указывать `published` и `lang`; свежая статья автоматически вытеснит самую старую из текущей шестёрки.
