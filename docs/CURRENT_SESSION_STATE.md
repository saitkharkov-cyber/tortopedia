## 3. Автоматизация блока «Последние статьи»

Ручное обновление сайдбаров больше не требуется.

В `eleventy.config.cjs` используются коллекции:

```text
recentRu
recentUk
```

Логика:

- берутся страницы с `published`;
- фильтрация по `lang`;
- сортировка по дате публикации по убыванию;
- выводятся последние 6 материалов.

Сайдбары:

```text

src/_includes/partials/sidebar-uk.njk
```

Для новой статьи достаточно корректно указать, например:


## 8. Следующая статья — задача на 2026-09-18

Следующая тема:

```text
сравнение отвердителей / укрепляющих добавок для мастики
```

Рабочий угол:

```text
CMC / Tylose / Gum-Tex и аналоги
```

Рабочая SEO-идея:

```text
Как сделать мастику твёрже для фигурок: CMC, Tylose, Gum-Tex и другие добавки
```

Но H1 и окончательный интент пока не фиксировать без повторной проверки семантики.

Задача статьи — не сделать узкий справочник по одной добавке, а дать практическое сравнение:

- что такое CMC / карбоксиметилцеллюлоза;
- что обычно называют Tylose powder;
- что такое Gum-Tex;
- какие есть аналоги и готовые укрепляющие смеси;
- чем они отличаются по назначению;
- как меняют пластичность мастики;
- как влияют на скорость высыхания;
- как влияют на прочность фигурок и деталей;
- когда отвердитель действительно нужен;
- когда можно обойтись без добавок;
- передозировка и типичные ошибки.

Перед написанием нужно:

1. проверить поисковый интент и кластер;
2. убедиться, что тема не каннибализирует статьи о сушке, хранении и лепке;
3. определить корректные названия/синонимы CMC, Tylose, Gum-Tex;
4. собрать надёжные источники по назначению и применению добавок;
5. только после этого утвердить структуру статьи.

Внутренняя перелинковка должна связать новую статью с кластером:

```text
лепка → укрепление/моделирование → сушка → хранение
```

## 9. Важное правило новой статьи

Не смешивать три разных интента:

```text
как сделать мастику пригодной для моделирования
как ускорить/улучшить высыхание
как правильно высушить готовую фигурку
```

Новая статья должна объяснять роль добавок в самой мастике. Статья «Как сушить фигурки из мастики» остаётся отдельным материалом о процессе сушки готовых изделий.
