## Уже подтверждено

### Интент

Основной запрос:

```text
торт для рыбака
```

Основной интент — найти идею и понять, как самостоятельно украсить торт для рыбака в домашних условиях.

Материал должен быть практической инструкционной статьёй с элементами вдохновения.

Это:

- не галерея готовых тортов;
- не рецепт коржей или начинки;
- не общий материал о мужских тортах.

Предусмотрены два самостоятельных технологических направления:

1. без мастики;
2. с мастикой.

Их нельзя смешивать.

### H1

RU:

```text
Торт для рыбака: как украсить своими руками
```

UA:

```text

```

### Основная структура

- как выбрать оформление;
- торт для рыбака без мастики;
- торт для рыбака с мастикой;
- как собрать оформление, чтобы торт не выглядел перегруженным.

Для композиции принят принцип:

**один основной сюжет + один главный акцент + несколько поддерживающих деталей + свободное пространство.**

## Вариант без мастики

Утверждённая технология:

- вода — тонкая светлая кремовая основа + голубой декоративный гель;
- основной домашний вариант геля — крахмальный;
- готовый нейтральный piping gel — удобная покупная альтернатива;
- берег — светлый крем + мелкая крошка светлого печенья;
- в воде — 1–2 простые рыбки, нарисованные кремом поверх геля;
- на берегу — съедобный поплавок из круглой конфеты;
- используется настоящая тонкая рыболовная леска со свободным или слегка спутанным мотком;
- крючок — только безопасная съедобная стилизация;
- настоящий металлический рыболовный крючок не использовать;
- настоящую леску обязательно полностью снять перед разрезанием и подачей торта.

---

## Вариант с мастикой

Весь торт сначала обтягивается базовой светлой мастикой.

Верх делится на две зоны:

- вода — отдельный тонкий пласт голубой мастики, примерно 1/3 поверхности;
- берег — отдельный тонкий пласт бежевой мастики, примерно 2/3 поверхности.

Вода остаётся пустой.

В ней нет:

- рыб;
- поплавка;
- лески;
- крючка;
- сачка.

Вся рыболовная сцена располагается на берегу.

На берегу:

- поплавок;
- леска с крючком-червячком;
- лежащий сачок с тремя рыбками;
- несколько простых пучков зелёной мастичной травы.

Камыши исключены.

### Сачок

Сачок должен быть реально повторим домашним кондитером.

Сетка:

- один тонкий кусок светлой мастики;
- на нём продавливается ромбический рисунок;
- кусок слегка сминается / собирается;
- добавляются коричневый обод и ручка.

Реальную плетёную сетку из множества отдельных полос не делать.

### Рыбки

Ровно три рыбки немного разного размера.

Конструкция:

- светлое овальное тело;
- красный хвост;
- красный боковой плавник;
- чёрный глаз;
- несколько рядов чешуи, продавленных инструментом.

Без аэрографа и сложной реалистичной росписи.

Главный визуальный акцент мастичного варианта:

**сачок с тремя рыбками.**

Поддерживающие детали:

- поплавок;
- леска;
- крючок-червячок;
- зелень.

## Изображения

Для Tortopedia действует итеративный принцип:

```text
идея
→ первая рабочая генерация
→ визуальная оценка
→ корректировка концепции
→ повторная генерация / редактирование
→ утверждение
```

Не считать первоначальный промпт окончательным техническим заданием.

Не проектировать окончательно все изображения статьи заранее.

После каждой генерации оценивать фактический результат и только затем решать:

- что оставить;
- что убрать;
- что изменить;
- нужна ли следующая генерация.

Технически подготавливать и интегрировать только изображения, утверждённые пользователем.
