# Tortopedia — START HERE

## Что это за проект

`tortopedia.in.ua` — восстановленная статическая версия старого WordPress-сайта о кондитерском декоре.

Текущая версия не использует WordPress/PHP как движок: сайт публикуется как набор HTML/CSS/JS и статических ресурсов.

Языки:
- русский — корень сайта;
- украинский — `/uk/`.

## Репозиторий

GitHub: `saitkharkov-cyber/tortopedia`

Основная ветка: `main`

Локальный репозиторий: `D:\Git\tortopedia`

## Хостинг и деплой

Сайт работает через Cloudflare Worker с Static Assets.

Деплой запускается автоматически после push в `main`.

Основные файлы:
- `wrangler.jsonc` — конфигурация Cloudflare;
- `.assetsignore` — исключает `.git` из публикации;
- `tortopedia.css` — общий CSS, вынесенный из inline-стилей страниц.

## JavaScript

Основной jQuery:

`/wp-includes/js/jquery/jquery.js`

Он должен подключаться на всех HTML-страницах до зависимых скриптов.

LightSlider нужен на двух главных страницах:
- `/index.html`;
- `/uk/index.html`.

Не возвращать LightSlider глобально на внутренние страницы без проверки фактического использования.

FlexSlider признан неиспользуемым и удалён.

## Изображения

Контентные изображения из `wp-content/uploads` оптимизированы в WebP.

Не конвертировать автоматически все PNG сайта: часть PNG относится к теме, интерфейсу, favicon и служебным ресурсам.

Перед удалением или заменой ресурсов обязательно проверять ссылки из HTML/CSS/JS.

## Git-проверка перед коммитом

```powershell
git status
git diff --stat
git diff --check
```

Предупреждения Windows вида `LF will be replaced by CRLF` сами по себе не являются ошибкой `git diff --check`.

После проверки:

```powershell
git add . && git commit -m "Описание изменений"
git push origin main
```
