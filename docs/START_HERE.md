# Tortopedia — START HERE

## Что это за проект

`tortopedia.in.ua` — восстановленная статическая версия старого WordPress-сайта о кондитерском декоре.

Текущая версия не использует WordPress/PHP как движок: сайт публикуется как набор HTML/CSS/JS и статических ресурсов.

Языки:
- русский — корень сайта;
- украинский — `/uk/`.

## Репозиторий

GitHub: `saitkharkov-cyber/tortopedia`

Основная ветка: `main`

Локальный репозиторий: `D:\Git\tortopedia`

## Хостинг и деплой

Production работает на Cloudflare Pages и связан с GitHub.

Схема публикации:

`локальная рабочая копия → GitHub main → Cloudflare Pages → tortopedia.in.ua`

Cloudflare Pages автоматически публикует изменения после push в `main`.

В перспективе допускается использование Eleventy (11ty) как локального генератора статического HTML, но сборка должна выполняться локально до публикации. В GitHub должен попадать уже проверенный итоговый HTML, чтобы сохранялся полный контроль над SEO-разметкой, URL и фактическим кодом страниц.

Основные файлы:
- `tortopedia.css` — общий CSS, вынесенный из inline-стилей страниц.

## Изображения

Контентные изображения из `wp-content/uploads` оптимизированы в WebP.

Следующий этап развития изображений — responsive images.

Для одинакового изображения с разным физическим размером использовать `srcset` + `sizes`. Минимально предусматривать варианты для экранов 1x / 2x / 3x. Практический базовый набор для контентных изображений: примерно `480w / 960w / 1440w`, если исходник позволяет.

`<picture>` использовать там, где действительно требуется другой источник: отдельный мобильный кроп, другой формат или иная композиция изображения.

Не заменять `<img>` на `<picture>` механически, если источник остаётся тем же. Для обычного responsive scaling предпочтителен `img` с корректными `srcset` и `sizes`.

Для новых и переработанных изображений сохранять явные `width` и `height`, корректный `alt`, а для изображений вне первого экрана использовать `loading="lazy"` и при необходимости `decoding="async"`.

Не конвертировать автоматически все PNG сайта: часть PNG относится к теме, интерфейсу, favicon и служебным ресурсам.

Перед удалением или заменой ресурсов обязательно проверять ссылки из HTML/CSS/JS.

## Важно

Это восстановленный архив старого WordPress-сайта, а не проект, разработанный заново. Поэтому старый файл нельзя считать ненужным только по имени или происхождению — сначала нужно подтвердить отсутствие реального использования.

Сначала проводится SEO-техническая ревизия существующих страниц: `/index/`-дубли, canonical, hreflang, sitemap, robots и внутренние URL. Только после стабилизации SEO имеет смысл экспериментально выделять шаблоны и контент в локальную 11ty-сборку.
