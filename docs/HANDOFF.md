## Архитектура сайта

Tortopedia работает через Eleventy.

Основные исходники:

```text
src\
```

Eleventy:

```text
input:  src
output: _site-pilot
```

Документация находится вне `src/`, поэтому `docs/` в production-сборку сайта не входит.

Удалять эти документы автоматически не нужно: в них остаётся полезная информация.

## Git

Все Git-команды теперь выполняются из:

```text
D:\Git\tortopedia
```

Перед коммитом:

```powershell
git diff --check
```

затем проверить содержательный diff и:

```powershell
git status --short
```

После staging:

```powershell
git diff --cached --check
git diff --cached --name-status
```

Commit и push — только после явного подтверждения пользователя.
