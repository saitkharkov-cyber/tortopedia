# Потенциальный ассортимент Tortopedia-shop

Рабочий документ для товаров, необходимость которых естественно возникает в материалах Tortopedia.

## Принцип отбора

Товар добавляется в список не ради расширения каталога, а когда он решает конкретную практическую задачу читателя в существующей или планируемой статье. При наличии простого домашнего способа статья может давать выбор: сделать самостоятельно или использовать готовый продукт.

## Кандидаты

### Нейтральный декор-гель / piping gel

- **Статус:** кандидат
- **Источник потребности:** статья «Торт для рыбака» (post_id: 1045)
- **Задача:** создание прозрачной или полупрозрачной воды на торте
- **Почему полезен:** позволяет быстро получить эффект воды без самостоятельного приготовления геля
- **Домашняя альтернатива:** крахмальный декоративный гель
- **Контентная логика:** сначала объяснить технику и домашнюю альтернативу; готовый продукт предлагать как удобный вариант, а не как обязательную покупку
- **До появления Tortopedia-shop:** при необходимости внешняя ссылка на подходящий товар
- **После появления Tortopedia-shop:** заменить внешнюю рекомендацию внутренней ссылкой на собственную карточку товара

## Метаданные статей

Если потребность в потенциальном товаре естественно возникает в статье, она может фиксироваться в FrontMatter отдельным служебным полем shop_opportunities. Поле не означает обязательную продажу или вывод товарного блока на странице.

```yaml
shop_opportunities:
  - product: neutral-piping-gel
    context: water-decoration
    status: candidate
```

- product — стабильный внутренний идентификатор потенциального товара.
- context — практическая задача, которую товар решает в конкретной статье.
- status: candidate — товар рассматривается для будущего ассортимента.
- status: active — товар появился в Tortopedia-shop и может быть связан с карточкой товара.

Наличие shop_opportunities не должно само по себе влиять на пользовательский контент статьи. Поле служит для накопления карты «контент → практическая потребность → потенциальный товар» и будущей интеграции Tortopedia-shop.
