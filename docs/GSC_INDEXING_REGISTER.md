## 4. Правило работы

Не делать массовые изменения сайта по этому списку.

Рабочий порядок:

```text
реестр
→ диагностика конкретного URL
→ подтверждение причины
→ только потом изменение сайта или запрос на индексирование
```

Все фактические изменения сайта выполнять в основном проекте Tortopedia, если пользователь отдельно не поручил иное.
