# Tortopedia — базовый план развития

> Рабочая версия. Принята как базовый маршрут и может совершенствоваться по мере появления новых данных, результатов тестов и изменения приоритетов.

## 1. Фундамент

- окончательно зафиксировать позиционирование;
- собрать новое семантическое ядро;
- разложить весь процесс изготовления торта на тематические кластеры;
- определить, какие разделы уже закрыты контентом, а каких не хватает.

## 2. Контентный каркас

Основные тематические направления:

- выпечка;
- кремы и начинки;
- сборка;
- выравнивание;
- покрытия;
- декор;
- хранение и транспортировка;
- ошибки и спасение результата.

Для каждого направления определить, какие материалы должны быть быстрыми инструкциями, а какие — большими руководствами.

## 3. Рост поискового трафика

- усиливать страницы, которые уже получают показы;
- создавать новые материалы по сильным незакрытым кластерам;
- развивать внутреннюю перелинковку;
- постепенно расширять RU/UA-контент.

## 4. Единый формат Tortopedia

Для ключевых практических инструкций придерживаться структуры:

**ответ сразу → пошагово → как должно выглядеть → строго не делать → как исправить ошибку**

Главные требования:

- скорость ответа;
- точность;
- наглядность;
- простота;
- доступность ингредиентов и инструментов;
- предупреждение грубых ошибок.

## 5. Внешние каналы

После формирования нормального контентного ядра тестировать внешние каналы по одному или небольшими группами:

- Pinterest;
- короткие видео;
- YouTube;
- другие площадки только после проверки пользы.

Не масштабировать канал до подтверждения результата.

## 6. Первый платный продукт

Не начинать с большого курса.

Сначала проверить платёжный спрос через небольшой продукт:

- мини-курс;
- PDF;
- технологическая карта;
- небольшой набор инструкций.

Тему выбирать по данным: что чаще ищут, где пользователи сталкиваются с проблемами, какие материалы вызывают повторный интерес.

## 7. Обучающая система

Если первый платный продукт подтверждает спрос:

- развивать серию мини-курсов;
- создавать маршруты обучения;
- переходить к большим курсам только там, где есть подтверждённая потребность.

## 8. Tortopedia Tools

Параллельно собирать реальные бытовые проблемы пользователей и проверять идеи собственных инструментов.

Приоритетные гипотезы:

1. разметочная лента для деления торта по окружности;
2. центровщик ярусов и опор;
3. универсальный разметчик декора.

Производство — только после проверки востребованности.

## 9. Мини-магазин

Создавать после появления данных о реальном спросе.

Возможные направления:

- собственные инструменты Tortopedia Tools;
- цифровые товары;
- небольшой проверенный физический ассортимент;
- товары, логично связанные с инструкциями и курсами.

## 10. Монетизация как система

Целевая цепочка:

**поиск / соцсети → бесплатная инструкция → возвращаемость → цифровой продукт → курс → инструменты / магазин**

## Ближайшие 90 дней

### Месяц 1

- семантическое ядро;
- карта тематических кластеров;
- сопоставление кластеров с существующим контентом.

### Месяц 2

- усиление старого контента;
- запуск первых новых кластеров;
- внедрение единого формата практических инструкций.

### Месяц 3

- тест одного внешнего канала;
- подготовка гипотезы первого платного продукта;
- сбор первых сигналов спроса для будущих Tortopedia Tools.

## Принцип пересмотра

Этот план не считается жёстким. Он служит базовой картой движения. Любой этап может быть скорректирован по данным GSC, поведению аудитории, результатам тестов, продажам и новым возможностям проекта.
