# HANDOFF — Tortopedia

Дата: 2026-09-05
Ветка: `main`

## Текущее состояние

Техническая миграция завершена. Production работает на Cloudflare Pages. Источник истины — Eleventy-исходники в `src`, готовые HTML в корне являются результатом локальной сборки.

Текущая схема:

`src + layouts/partials → npm run build → _site-pilot → publish.ps1 → production HTML в корне → GitHub main → Cloudflare Pages`

Cloudflare сам Eleventy не собирает.

## Eleventy и публикация

- Eleventy 3.1.6
- input: `src`
- output: `_site-pilot`
- текущая контрольная сборка: **52 HTML-файла**
- `publish.ps1` должен ожидать ровно 52 HTML-файла
- `_site-pilot/`, `node_modules/`, `backup/` игнорируются Git

Количество уменьшилось с 54 до 52 после удаления дублирующей пагинации категории `vse-o-mastike/page/2/` RU/UA.

Рабочий цикл:

1. редактировать `src` и шаблоны;
2. выполнить `./publish.ps1`;
3. проверить diff;
4. commit;
5. push в `main`;
6. при важных изменениях проверить production.

Важно: `publish.ps1` сейчас не очищает `_site-pilot` перед сборкой. Уже был случай, когда удалённые page/2 остались в старом output и были скопированы обратно. Перед изменениями, связанными с удалением страниц, очищать `_site-pilot`; позже можно добавить очистку прямо в скрипт.

## Правила работы

- PowerShell-команды давать одной строкой;
- исходники HTML для вставки давать без пустых строк между тегами;
- для демонстрации код можно форматировать свободнее;
- сначала обсуждение → согласование → только потом фиксация в документации;
- после failed build не доверять старому `_site-pilot`;
- `git diff --check` должен проходить;
- production URL-структуру без причины не менять.
