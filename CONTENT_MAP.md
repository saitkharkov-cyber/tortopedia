# Tortopedia — карта контентных кластеров

> Живой рабочий документ. Фиксирует принятую структуру контента и развивается по мере появления новых данных GSC, семантики и новых разделов.

## 1. Первый пилотный кластер: «Мастика»

Исторически мастика — самая сильная тема Tortopedia по текущим данным GSC. Этот раздел принимается как первый полноценный пилотный кластер, на котором отрабатывается будущая архитектура всей Tortopedia.

Важно: текущая выгрузка GSC содержит отдельно запросы и отдельно страницы, но не даёт точной связки `запрос → URL`. Поэтому распределение запросов по страницам пока считается рабочей семантической картой и позже может уточняться через фильтры GSC или API.

## 2. Структура кластера «Мастика»

### 2.1. Базовая страница темы

Главная pillar page:

**Как сделать сахарную мастику в домашних условиях: 8 рецептов**

Она должна закрывать широкий общий интент:

- мастика рецепт;
- рецепт мастики;
- как сделать мастику;
- мастика для торта;
- мастика в домашних условиях;
- сахарная мастика;
- мастика своими руками;
- простой рецепт мастики.

Не создавать отдельные страницы под почти одинаковые формулировки, если интент совпадает.

### 2.2. Рецепты по типу мастики

Существующие отдельные направления:

- мастика из маршмеллоу;
- шоколадная мастика;
- желатиновая мастика;
- мастика из сгущёнки.

Потенциальные отдельные страницы после проверки спроса:

- мастика без желатина;
- мастика для цветов;
- специальная мастика для лепки фигурок.

### 2.3. Работа с мастикой

Существующие направления:

- как обтянуть торт мастикой;
- как обтянуть без складок;
- какая мастика лучше для обтяжки;
- обтяжка мастикой из маршмеллоу;
- мраморная мастика.

Недостающий системный материал:

**Как работать с мастикой для начинающих**

Предполагаемая структура:

подготовка → разминание → раскатка → толщина → перенос → обтяжка → обрезка → хранение остатков.

### 2.4. Окрашивание

Отдельный сильный кластер.

Базовая страница:

**Как покрасить мастику: красители, способы и типичные ошибки**

Она должна объединять интенты:

- как покрасить мастику;
- чем красить мастику;
- каким красителем красить;
- можно ли окрашивать готовую мастику;
- окрашивание в сложные цвета;
- роспись по поверхности.

Не создавать отдельные статьи под каждый цвет без подтверждённого отдельного спроса.

### 2.5. Лепка и фигурки

Существуют отдельные мастер-классы по конкретным фигуркам.

Нужна базовая страница кластера:

**Мастика для лепки фигурок: рецепт, консистенция и работа**

Она должна стать входной страницей для запросов про мастику для фигурок и связывать базовую технику с отдельными мастер-классами по лепке.

### 2.6. Ошибки и спасение результата

Стратегически важный, почти не покрытый сейчас блок.

Потенциальные темы:

- мастика липнет;
- мастика рвётся;
- мастика трескается;
- слишком мягкая;
- слишком твёрдая;
- быстро сохнет;
- потеет;
- пузырится;
- складки при обтяжке;
- плохо раскатывается;
- как спасти испорченную мастику.

Этот блок особенно соответствует позиционированию Tortopedia: быстрый, точный и практичный ответ человеку, который уже готовит и столкнулся с проблемой здесь и сейчас.

## 3. Принцип архитектуры контента

Для раздела «Мастика» принимается базовая логика:

**базовый ответ → конкретная техника → troubleshooting**

В более широкой форме:

**что делать → как должно выглядеть → строго не делать → как исправить ошибку**

Этот принцип затем можно переносить на другие разделы Tortopedia: выпечку, кремы, начинки, сборку, выравнивание, покрытия, декор, хранение и транспортировку.

## 5. Аудит текущих материалов

### 5.1. Есть и уже достаточно хорошо

**Мастика из маршмеллоу**  
Страница уже усилена: точные пропорции, пошаговый рецепт, варианты микроволновка/водяная баня, отдельные пояснения для обтяжки и фигурок. По текущим данным GSC это самый сильный кластер по кликам и CTR. Пока не переписывать, возвращаться к ней только по точечным данным.

**Как сделать сахарную мастику в домашних условиях: 8 рецептов**  
Уже усилена и выполняет роль основной pillar page широкого интента. Потенциал роста большой, но сейчас важнее развивать недостающие и слабые части кластера, а не снова переписывать базовую статью.

### 5.2. Есть, но нужно усилить

**Как покрасить мастику красителем**  
Контент объёмный и тематически широкий, но структура слишком энциклопедическая для пользователя, которому нужен быстрый ответ. По GSC есть заметные показы при практически отсутствии кликов. Приоритет: улучшить title/seo_title, первый экран, быстрый ответ и блок ошибок.

**Обтяжка торта мастикой**  
Кластер уже представлен несколькими материалами: обтяжка без складок, обтяжка маршмеллоу, выбор мастики для обтяжки. Нужно определить главную страницу кластера и роли вспомогательных материалов, убрать возможную каннибализацию и усилить внутреннюю перелинковку.

**Мастика из желатина**  
Страница есть и имеет спрос, но требует отдельной проверки качества, интента и соответствия текущим запросам.

**Мастика из сгущёнки**  
Поддерживающий рецепт. Пока низкий приоритет: сначала проверить спрос и качество страницы, без крупной переработки.

**Шоколадная мастика**  
Страница есть, но по текущей GSC-выгрузке почти не получает кликов при наличии показов. Нужна проверка сниппета, структуры и соответствия запросу.

**Мраморная мастика**  
Полезная техника, но относится ко вторичному уровню кластера. Усиливать после базовых направлений.

**Фигурки из мастики**  
Есть отдельные мастер-классы: пингвин, Лунтик, зайчик, пасхальные фигурки, M&M и другие. Главный недостаток — нет базовой страницы, которая собирает интент «мастика для лепки фигурок» и ведёт к этим мастер-классам.

### 5.3. Страницы нет

**Как работать с мастикой для начинающих**  
Нужна системная базовая инструкция: подготовка → разминание → раскатка → толщина → перенос → обтяжка → обрезка → хранение.

**Мастика для лепки фигурок: рецепт, консистенция и работа**  
Отдельная базовая страница под прямой пользовательский интент и вход в кластер лепки.

**Ошибки при работе с мастикой / как спасти результат**  
Стратегически важный блок: липнет, рвётся, трескается, сохнет, потеет, слишком мягкая, слишком твёрдая, пузырится, плохо раскатывается, складки при обтяжке. Это направление особенно соответствует позиционированию Tortopedia как быстрой практической помощи «здесь и сейчас».

**Мастика без желатина**  
Пока только гипотеза отдельной страницы. Перед созданием проверить внешний спрос и убедиться, что интент нельзя достаточно хорошо закрыть существующей pillar page.
